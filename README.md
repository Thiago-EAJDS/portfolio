# Portfólio — Thiago Araújo

Portfólio pessoal de Thiago Emanuel Araújo Jorge de Sá, desenvolvido com HTML5, CSS3 e JavaScript e hospedado na Vercel.

**Acesse:** [portfolio-thiagoaraujo.vercel.app](https://portfolio-thiagoaraujo.vercel.app/)

## Seções

- **Início:** apresentação, foto de perfil, status de disponibilidade e links sociais.
- **Sobre mim:** bio, competências por categoria e contatos diretos.
- **Tecnologias e habilidades:** cards filtráveis por categoria, com indicador de nível.
- **Projetos:** cards filtráveis por tipo, com descrição, destaques e link para o repositório.
- **Experiências profissionais:** linha do tempo profissional e certificações.

## Funcionalidades

- Tema claro e escuro, com a preferência salva em `localStorage`
- Fundo animado em canvas
- Layout responsivo, pensado primeiro para mobile
- Filtros de tecnologias e projetos por categoria
- Animações de entrada ao rolar a página

## Tecnologias

| Tecnologia | Uso |
|---|---|
| HTML5 | Estrutura e semântica |
| CSS3 | Estilização, variáveis CSS e responsividade |
| JavaScript (ES6+) | Interatividade, canvas, tema e filtros |
| Vercel | Hospedagem e deploy contínuo |
